# Project Memory

## Core
Complete anonymity: no user accounts, emails, progress tracking, or personal dashboards.
Team data is intentionally public via `team_id` for live event simplicity. No auth.
No automatic interpretation or text recommendations for results; visual radar only — EXCEPT Tonus radar (`/resource-radar`), which shows archetype text by user agreement.
No central home page; assessment tools are accessed via direct URLs. Blue Ocean is default `/`.

- [Rejected Interpretation Logic](mem://features/rejected-interpretation-logic) — Auto-interpretation forbidden by default; Tonus radar archetype is the only sanctioned exception.
