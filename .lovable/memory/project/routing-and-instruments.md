Five instruments, each at its own route:
1. **Blue Ocean Radar** — `/` (default) and `/blue-ocean` — диагностика бизнеса
2. **Leadership Radar** — `/leadership-radar`
3. **Indicator Radar** — `/indicator-radar` — индикаторы
4. **Resource / Tonus Radar** — `/resource-radar` — тонус-менеджмент, 4 архетипа (Visionary / Deep Worker / Empath / Biohacker), 36 утверждений
5. **EdTech Risk Management Radar** — `/edtech-risk` — риски EdTech-бизнеса, 6 блоков (регуляторные, продуктовые, технологические, данные/приватность, финансовые, репутационные)

No central home page. Blue Ocean is the main product. InstrumentNav (admin-only, Ctrl+Shift+N or `?nav=1`) lists all instruments.

Tonus radar logic: «Да» = утечка ресурса. Доминирующий блок (с макс. количеством «Да») определяет архетип — это исключение из правила «no auto-interpretation», специально согласованное с пользователем для этого инструмента.
