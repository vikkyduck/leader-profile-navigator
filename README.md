# Leader Profile Navigator

Набор диагностических радаров для командной и личной оценки: человек отвечает на
вопросы инструмента, получает радар-диаграмму, интерпретацию и PDF. В командном
режиме ответы собираются анонимно и показываются средним по команде.

Прод: **http://5.129.198.180:8090/**

## Инструменты

| Маршрут | Инструмент |
| --- | --- |
| `/` и `/blue-ocean` | Голубой океан |
| `/leadership-radar` | Радар лидерства |
| `/indicator-radar` | Радар индикаторов |
| `/resource-radar` | Радар ресурсов |
| `/edtech-risk` | Риски EdTech |
| `/motivation` | Мотивация профессиональной деятельности |
| `/motivation/team` | Средние по команде для мотивации (по ключу) |

Содержание первых пяти инструментов (блоки, критерии, тексты интерпретаций)
описано данными в `src/data/*.ts` — экраны общие, различается конфигурация.
Мотивация устроена отдельно: 15 мотивов и две оценки 1–10 на каждый.

## Стек

Vite + React 18 + TypeScript, Tailwind и shadcn/ui, recharts для радаров,
jsPDF для выгрузки. Данные — собственный бэкенд на том же сервере (`server/`),
хранилище SQLite. Внешних облаков нет: ответы не покидают этот сервер.

## Локальный запуск

```sh
npm install
npm run dev
```

Фронт ходит в `/api`, поэтому для полноценной работы нужен бэкенд:

```sh
ADMIN_KEY=любой-ключ DB_PATH=./local.db PORT=5040 node server/index.js
```

и прокси с `/api` на `127.0.0.1:5040` (в проде это делает nginx).

## Бэкенд

`server/index.js` — приём анкет и подсчёт средних, без единой зависимости
(`node:http` + `node:sqlite`, нужен Node 22+).

| Маршрут | Кто может |
| --- | --- |
| `POST /api/responses` | все — отправка анкеты |
| `GET /api/responses/:instrument/:teamId` | все — среднее по команде |
| `GET /api/motivation/summary?key=` | только по ключу |
| `GET /api/motivation/rows?key=` | только по ключу |
| `GET /api/export?key=` | только по ключу — все ответы разом |

Мотивация — исключение: её средние публичным маршрутом не отдаются (`403`),
участник видит только собственный профиль. Ключ лежит в
`/opt/radars-api/radars-api.env` на сервере и в репозиторий не попадает.

На сервере бэкенд запускается юнитом `radars-api.service`, база —
`/opt/radars-api/data/radars.db`.

## Деплой

```sh
./deploy.sh
```

Сборка идёт локально (`vite build`), на Timeweb VDS уезжает только `dist/`
(rsync в `/opt/leader-navigator/dist`), раздаёт nginx на порту 8090. Бэкенд
обновляется отдельно: `rsync server/index.js` в `/opt/radars-api/` и
`systemctl restart radars-api`.

## Данные

Ответы анонимны: ни имени, ни почты, ни IP — код команды и оценки. Забрать все
данные к себе на компьютер:

```sh
./server/pull-data.sh
```

Кладёт файл базы и JSON-выгрузку в `~/Documents/Радары-данные/<дата>/`.
